# Journal Tracker v4.2 更新看板重构版

## 更新重点

本版本根据展示逻辑重新设计看板：

1. 不再展示 fetched / 抓取次数，避免把接口原始返回条目误解为论文数量。
2. 首页核心指标改为“今日更新”“所选日期更新”“覆盖期刊”“专题命中”“收藏”。
3. 左侧栏增加期刊列表，点击任一期刊即可查看该期刊在所选日期的更新论文。
4. 左侧栏增加“选择更新日期”，可查看非当天的历史更新文章。
5. 论文展示改为卡片式，点击论文标题展开摘要、链接、DOI、PubMed、原文页面和阅读管理。
6. 文章可以按“卡片 / 按期刊 / 按主题”三种方式展示。
7. 系统状态页仍保留错误排查，但不展示 fetched 次数。

## 替换方式

复制以下文件覆盖到项目对应位置：

- `app.py` → 项目根目录
- `src/database.py` → `src` 文件夹
- `docs/UPDATE_V4_2_UI_REDESIGN.md` → `docs` 文件夹

替换后运行：

```powershell
python -m src.main init-db
streamlit run app.py --server.port 8502
```

打开：

```text
http://localhost:8502
```

## 注意

数据库不需要删除，原有论文记录、收藏、备注、阅读状态都会保留。
